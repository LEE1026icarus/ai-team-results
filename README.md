# AI Team Results

이카루스팀의 AI 조직 작업 결과물 레포지토리입니다.

## 디렉토리 구조

```
ai-team-results/
├── results/       ← 최종 결과물 (연구, 분석, 보고서)
├── summaries/     ← 작업 완료 요약 (자동 생성)
├── incidents/     ← 장애 기록 (인시던트 리포트)
├── jobs/          ← 작업 정의 (Job 메타데이터)
└── handoffs/      ← 팀 간 전달 문서
```

## 관리 정책

| 분류 | 대상 | 저장소 |
|------|------|--------|
| **Git** | 설계, 설정, 최종 결과, 짧은 요약, 장애 기록 | 이 레포 |
| **로컬/서버** | raw log, 임시 파일, 캐시, 대용량 산출물 | hermes_bridge |
| **외부 저장소** | 장기 보관 로그, 원본 데이터, 대용량 결과 | Object Storage |
